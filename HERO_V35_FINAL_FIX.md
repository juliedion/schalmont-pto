# V3.5 final hero fix

This version removes the previous V3.2/V3.3/V3.4 composition overrides and uses one authoritative hero system.

Key corrections:
- Full supplied Fort/grass asset is rendered at 100% width again.
- Hero height scales with viewport width so the Fort roof is no longer cropped.
- No separate grass filler exists, eliminating the left-side artifacts.
- Sun is smaller, farther right, and behind the right cloud.
- Soft cloud assets remain small and positioned like the approved reference.
- Plane is restored and starts with a negative animation delay so it is visible soon after load.
