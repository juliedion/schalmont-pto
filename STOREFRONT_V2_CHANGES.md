# Fort Crazypants Storefront V2

Combines the affiliate/discovery architecture from Storefront V1 with the visual personality of the existing Fort Crazypants Shopify site.

## Changes
- Uses the supplied Fort Crazypants logo in the navy header.
- Adds a hot-pink announcement bar with affiliate-appropriate messaging.
- Rebrands the hero around “Crazy cool finds you’ll actually use.”
- Adds a playful illustrated Fort scene without relying on external image assets.
- Changes retailer-style language to discovery/editorial language.
- Adds colorful collection chips inspired by the current live brand.
- Keeps Trending Finds, Road Trip Rescues, Under $25, Crazy List, newsletter, individual Find pages, and affiliate disclosures.
- Keeps demo data for now; Shopify/Find Engine connection is the next data phase.
